# Customer Feedback System

## Technologies Used 

- Java 25
- Spring Boot
- Spring Data JPA
- MySQL
- Thymeleaf
- HTML
- CSS
- Maven

## Features

### User Module
- User Registration
- User Login
- Add Feedback
- Edit Feedback
- Logout

### Admin Module
- Admin Login
- View All Feedback
- Edit Feedback
- Delete Feedback
- Logout

## Database 

- User Table
- Feedback Table
