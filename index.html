Customer Feedback System

A full-stack application developed for JForce demonstrating secure authentication, session handling, CRUD feedback flows, and administrative oversight.

Explore Specifications View Screens

Requirement Gathering

Software Requirement Specification (SRS)

Functional Requirements

  • User Registration & Profile Creation
  • Secure User Login & Session Handling
  • Create and Edit Feedback Entries
  • Dedicated Admin Login Portal
  • Global Feedback Management Dashboard
  • Admin Edit & Delete Privileges
  • Safe Logout & Session Invalidation

Non-Functional Requirements

  • Intuitive & Responsive UI/UX
  • Fast Query Execution & Page Rendering
  • Streamlined Navigation Workflow
  • Session-Based Authentication Protection
  • Relational MySQL Data Store
  • Clean MVC Architectural Separation
